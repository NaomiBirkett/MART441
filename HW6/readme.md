For this project, I ended up with a great issue for practicing my debugging skills. I got my code all entered and thought everything was set up the way I wanted, but when I ran it, I ended up with a blank page and no errors in the console. I went to ChatGPT to review my code and see if it could help me figure out where my issue was, but it kept asking me to check the location of my images and verify that my style and script files were referenced correctly in my index file. Since none of those things were incorrect, I felt stuck on where I had gone wrong. After some trial and error, I ended up just reading through my index file line by line and eventually realized that when I had bumped my keyboard and then corrected some mistyping that ocurred earlier, I'd accidentally deleted the backslash in the end title tag. Once I added that back in, everything worked correctly! It's funny how such a simple error could completely break your code.

When I plugged the project parameters into ChatGPT, it made something fairly similar to what I had created. The biggest difference was that instead of using a div table to display the rows and columns, it used a grid display in the css file, which made the HTML file much cleaner. I also noticed that while I'd made my image array with my image array with images 1-12, the AI used images 1-6 and just listed them twice to make 12. I am not sure if one way is better than the other, but they both seemed to load the project correctly so I guess I won't worry about it too much.
